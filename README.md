Geo Project 🌍
Образовательное приложение на Django для изучения географии мира



Функционал:

* Просмотр списка стран
* Добавление и редактирование стран
* Викторина по географии



Инструкция (как использовать):

1. Убедитесь, что у вас установлена библиотека Django
2. Клонируйте репозиторий
3. Перейдите в папку репозитория при помощи cd
4. Введите команду: python manage.py migrate
5. Введите команду: python manage.py load\_countries
6. Введите команду: python manage.py runserver
7. Откройте в браузере: http://127.0.0.1:8000/
